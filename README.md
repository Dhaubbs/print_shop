# print_shop

This project is going to be a way for me to build a little system so I can learn the fundamentals of observability.
It's going to simulate a small printshop in which customers iteract with an API, which then sends that off to a queue for a worker function to print off their artwork all while storing the history of those orders in a database. Ideally, I'll be able to use a payment mockup api in order to inject failure points into the system in order to learn about o11y and such. At the time of writing, I'm kind of in the "you don't what you don't know" stage.
